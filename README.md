# DSG Android Test Automation Framework

This framework uses Espresso and Cucumber for BDD-style UI testing of the DSG Android app.

## Structure
- Step Definitions: `app/src/androidTest/java/com/dsg/stepdefinitions/`
- Page Objects: `app/src/androidTest/java/com/dsg/pageobjects/`
- Utilities: `app/src/androidTest/java/com/dsg/utilities/`
- Hooks: `app/src/androidTest/java/com/dsg/hooks/`
- Runner: `app/src/androidTest/java/com/dsg/runner/`
- Feature Files: `app/src/androidTest/resources/features/`

## Running Tests
Use Android Studio or Gradle to execute the tests via the TestRunner class.
